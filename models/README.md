# Reference Classification Models

This directory is intended for reference implementations of the five machine-learning model families discussed in the manuscript:

- XGBoost
- LightGBM
- Random Forest
- Logistic Regression
- K-Nearest Neighbors (KNN)

The reference implementations are provided for methodological exploration and adaptation by other researchers.

These scripts are not the original analysis code and have not been verified as reproducing the reported study results.

Researchers should independently establish appropriate preprocessing procedures, participant-level data splitting, hyperparameter tuning, and model validation before interpreting results.

No individual-level health data are included.
